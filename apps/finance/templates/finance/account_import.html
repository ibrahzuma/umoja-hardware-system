File layout

One row per ledger. Existing codes are updated; new codes are created. List a group before the ledgers under it.

  1. Code - unique account code
  2. Name - ledger name
  3. Type - Asset, Liability, Equity, Income or Expense
  4. Parent Code - group / control account it sits under (optional)
  5. Kind - blank (ordinary ledger), Group, Bank, Cash, Output VAT, Input VAT, Customer Control, Supplier Control
  6. Opening Balance and Dr/Cr (optional)
  7. Description (optional)

The template's Existing accounts sheet lists what is already in the chart.
